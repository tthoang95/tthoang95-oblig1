# Hello Health App

This project is a part of the obligatory assignement 1 for the course DATA1300 - Rapid developement with scription-language.
The focus is to create a virtual evironment, lear the Git workflow and how to structure a repository.
And of course track our health (physically and mentally) when doing this assignment. Currently the score of the health is 89/100.


## Installation Instructions


### 1 - Cloning the repository

1. On gitHub, navigate to the repository.
2. On the main page, look for the quick setup field and copy the command line using HTTPS.
3. Open Terminal.
4. Change to the directory location where you want to clone your directory.
5. Type git clone`and paste the URL that you copied from GitHub. 
```
 git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
```

### 2 - Creating a virtual environment

1. Open Terminal.
2. Change to the directory where you want to create a virtual environment.
3. Type `python3 -m venv venv`


### 3 - Activating the virtual environment

1. Open Terminal.
2. Change to the directory where you want to create a virtual environment.
3. Type `source venv/bin/activate`


### 4 - Running the application 

1. Open Terminal.
2. Change to the directory where you want to create a virtual environment. 
3. Activate your virtual environment.
4. Type `python name_of_your_file.py`


## Requirements

* Python 3.10 or higher
